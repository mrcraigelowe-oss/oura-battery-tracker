# Privacy Policy — Oura Battery Tracker

**Last updated:** 11 October 2026

## 1. About this project

Oura Battery Tracker is a personal project intended to help its owner monitor Oura Ring battery levels, charging cycles, and battery performance over time.

## 2. Information collected

The project may use battery-level readings and related timestamps obtained through the Oura API, subject to the permissions granted by the account owner.

The current website is informational and does not itself provide battery tracking functionality.

## 3. How information is used

Information obtained for the tracker is intended to be used to display battery history, estimate battery usage, and identify changes in battery performance.

## 4. Storage and security

Access credentials should be kept private and must not be published in the project's public source code. Any future implementation should use appropriate safeguards for credentials and personal data.

## 5. Sharing

The project is intended for personal use. Personal account data and access credentials should not be deliberately published or shared through the project website.

## 6. Third-party services

The project may use services provided by Oura Health and GitHub. Their respective privacy policies apply to their own services.

## 7. Contact

For questions about this project, contact the project owner through the GitHub repository.

## 8. Changes

This policy may be updated as the project develops.
